## Decisions (with reasoning)
- **Supabase + Next.js, local-first:** RLS gives per-row access checks; everything mutating goes through RPCs so race safety lives in SQL.
- **Colima instead of Docker Desktop:** Docker Desktop needs an admin password; Colima installs via Homebrew without one.
- **pg_cron + pg_net as the scheduler:** Vercel free plan only runs cron once a day; the database can call the worker every minute for free, so reminders work with nobody online.
- **Opus 5.5 for moderation and questions, effort low:** quality during the pilot (~$0.45/conversation); per-task overrides exist (`ANTHROPIC_MODEL_MODERATION`, `ANTHROPIC_MODEL_QUESTIONS`) to cut cost later.
- **Gmail SMTP for sign-in and notices:** no domain yet; Resend needs a verified domain. Capped ~500/day.
- **Daily shared hour 6–7 pm Pacific:** one simultaneous session; schedule is config, implemented once in `src/lib/schedule.ts` + SQL `session_window()`.
- **Questionnaire v2 scoring:** normalized 0..1 per question, mean per-issue distance over ≥5 shared answers; thresholds 0.40 strict / 0.20 relaxed / 0 anyone (provisional). Not-sure/declined stored separately, never a midpoint.
- **Badges show coarse tiers to the partner, exact counts only to self.**
- **Admins skip onboarding and land on Review;** they can opt in to participate.

## Gotchas
- Host vs local-Supabase clocks (Colima VM) differ by ~100 ms; tests must bound read marks with server timestamps (message `created_at`), never `Date.now()`. The real client already does this.
- Tests leave `policy_config` session_start_time/duration on the test window; reset to "18:00"/60 via psql before manual QA of the homepage/lobby.
- Supabase realtime: `sb.channel(name)` returns an existing channel of that name, and a subscribed channel throws on `.on(...)`. Any hook used by more than one mounted component must use a unique channel name per instance (`useUnread.ts`).
- `create or replace function` with a new default parameter leaves the old overload in place; drop the old signature explicitly (migration 0010, `mark_thread_read`).
- Dev server staleness: after editing a client component that a server component imports (e.g. `TabBar` from `Nav`), the SSR bundle can stay stale and the console shows a hydration mismatch that isn't in the code; restart `npm run dev` (via the browser pane's `web` launch config) before chasing it. Never run `next build` while `next dev` is running: it overwrites `.next` under the dev server.
- `read_console_messages` in the browser pane keeps old errors across reloads; judge by whether the count grows, or by the Next overlay badge.
- Test fixtures must use allowlisted push endpoints (e.g. `https://fcm.googleapis.com/fcm/send/test-…`); `push.invalid` is now rejected by the DB.
- iOS calendar preview: the top-right check mark closes without saving; only the bottom "Add To Calendar" button saves. A hint was added under the calendar buttons (`src/components/ReminderControls.tsx`) after the user's real-device test (2026-10-20). The .ics itself rendered correctly on iPhone (18:00–19:00, repeats daily, 10-min alert, link).
- `.env.local` is git-ignored; hosted keys live in `.vercel/hosted.env.local` and the prod cron secret in `.vercel/cron-secret.local` (both ignored). Vercel env: `--type config` for plain values; secrets default.
- Supabase CLI is the npm one (`npx supabase`), logged in; `npx supabase db push --yes` works non-interactively. Set `PATH=/opt/homebrew/bin:$PATH` and `DOCKER_HOST=unix://$HOME/.colima/default/docker.sock` for local `migration up`.
- The browser pane shares one cookie jar: two signed-in users need the partner harness (`scripts/qa-partner.mjs`) or `scripts/test-login-link.mjs` for a hosted test account. Background tabs throttle timers; don't read "stale" lobby state from a hidden pane as an app bug.
- PostgREST embeds from `participants` to `conversations` must use the FK hint `conversations!participants_conversation_id_fkey`.
- `conversation_questions.rationale_internal` is column-revoked: `select *` from a client fails by design.
- Tests leave the local session window open; `openSessionNow()`/`closeSessions()` in `tests/helpers.ts` control it. Local policy_config may need `session_start_time` reset to "18:00" afterwards for manual QA.
- Lint: no `Date.now()` in render, no sync `setState` in effects (defer with `setTimeout(…, 0)`).
- `AGENTS.md` is auto-generated by `next dev`; keep it committed as-is.
